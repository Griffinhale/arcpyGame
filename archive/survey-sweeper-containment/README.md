# Survey Sweeper / Containment Archive

This directory preserves the earlier project direction before Permit Office became the active focus.

## Contents

- `ideas/`: planning notes, feasibility research, Delphi-style concept analysis, Survey Sweeper plans, Containment plans, and GUI spike notes.
- `toolbox/`: old ArcGIS Pro spike toolboxes and the pure Survey Sweeper rules module.
- `tests/`: old Survey Sweeper rule tests, renamed so default `pytest` discovery does not collect them.
- `hermes-plans/`: old generated implementation plan artifacts.
- `root-readme-brainstorm.md`: the former root README with broader concept brainstorming.

## Status

These files are archived for reference only. They should not be treated as active product scope, active test targets, or current implementation guidance unless the project intentionally reopens this direction.

The active product is Permit Office, documented from the repo root README and `docs/current-status.md`.
